# 适航法规问答系统研发背景与设计思路

## 一、研发背景

航空器适航工作需要准确查找适用的规章条款、咨询通告和管理程序，并结合航空器类别、审定阶段及具体审定基础理解要求。以中国民航法规体系为例，CCAR-21 涉及民用航空产品和零部件的合格审定程序；不同类别航空器还需查阅相应适航标准及项目适用文件。

法规文件篇幅较长、分布在不同来源，条款之间也存在引用关系。工程师和研究人员提出一个具体问题时，通常需要先确认适用对象和文件版本，再定位原文依据。通用大模型如果脱离原文生成回答，可能出现条款误引、遗漏适用条件或编造依据。

AeroRegQA 因此定位为**适航法规检索与问答辅助工具**：让用户上传所需文件，建立可检索的知识库，并在回答中提供来源线索，方便回到原文核查。

## 二、核心问题

1. **法规定位耗时**：一个问题可能涉及规章、咨询通告和管理程序，需要跨文件查找相关条款。
2. **适用条件容易遗漏**：航空器类别、审定阶段、文件版本和条款中的限定条件会影响答案。
3. **模型回答需要核对**：仅给出流畅结论不足以支持适航工作，回答还应说明依据来自哪里、上下文是否足够。

## 三、系统设计

1. **文档解析与分块**：解析用户上传的 PDF、DOCX、TXT、Markdown 和 CSV 文件，按文档结构切分后建立索引。
2. **检索增强问答**：根据问题检索相关内容，要求模型依据检索片段回答，并附上可回查的来源信息。
3. **回答质量检查**：使用评估模块检查事实一致性、完整性和引用情况；结果不足时重新检索或生成。
4. **多轮对话**：结合会话历史改写后续问题，处理“该条款”“这个要求”等指代。

## 四、使用边界

系统的回答取决于用户上传的文件及其版本。未入库、已失效或不适用的文件可能影响结果；模型评估也不能替代人工核查。涉及正式审定、符合性判断或适航批准时，应以现行有效文件和主管机构意见为准。
