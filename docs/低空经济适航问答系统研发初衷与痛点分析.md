# 低空经济适航与规章问答 Agent 研发初衷与行业痛点分析

## 一、 研发背景与初衷

随着国家将“低空经济”确立为战略性新兴产业，eVTOL（电动垂直起降飞行器）、大中型无人机等新型航空器的研发与运营迎来了爆发式增长。作为南京航空航天大学的研究生，我们深刻认识到：**在航空领域，技术的突破固然重要，但“适航合规”才是决定航空器能否合法飞上蓝天、能否实现商业化运营的最终门槛。**

然而，目前的低空经济产业链中，适航审查与法规解读面临着巨大的痛点。为了解决这一痛点，提升行业研发效率，并对接未来民航局适航审定中心、商飞、大疆、亿航等核心企业的就业需求，我们研发了本套**“低空经济适航与规章问答 Agent”**。

---

## 二、 行业核心痛点分析

### 1. 规章体系极其庞杂，研发人员“查规难”
中国民航局（CAAC）的适航规章体系（CCAR 系列）极为庞杂。一款新型 eVTOL 的研发，可能同时涉及 CCAR-21部（合格审定）、CCAR-23部（正常类飞机）、专门的专用条件（Special Conditions）以及数以百计的咨询通告（AC）和管理程序（AP）。
**痛点**：一线的气动、结构、电池工程师往往缺乏适航背景，在进行设计决策时（如：电池系统的防火要求是什么？），需要在数千页的 PDF 规章中逐字检索，耗时极长且容易遗漏关联条款。

### 2. 通用大模型（如 ChatGPT）存在致命的“幻觉”，无法用于航空安全
目前市面上虽然有许多大模型工具，但它们在回答航空规章问题时存在**不可容忍的缺陷——“幻觉”**。大模型可能会根据网上的随机资料，拼接出一条看似专业、实则根本不存在的法规。
**痛点**：航空无小事。如果工程师轻信了大模型编造的合规标准进行设计，将导致几百万的研发成本打水漂，甚至在未来的试飞中引发灾难性事故。行业亟需一个**“100%忠于原始规章、且能溯源到具体条款号”**的智能工具。

### 3. 多轮咨询与法规演进的复杂性
低空经济是新兴领域，许多法规（如《无人驾驶航空器飞行管理暂行条例》）是在近年才颁布或修订的。传统基于关键字的搜索引擎，无法理解工程师口语化的复杂提问（例如：“这款 500kg 级的无人机，在城市人口密集区飞行，需要什么适航证？”）。

## 三、 本系统的核心解决方案与价值

针对上述痛点，本系统在技术架构上做出了极具针对性的创新：

1. **Agentic RAG（检索增强智能体）架构**
   我们将最新的适航规章文件解析、分块并存入本地向量数据库。当工程师提问时，系统首先去规章库中检索相关条款，然后强制大模型**只根据检索到的条文进行回答**，彻底杜绝了大模型凭空捏造适航标准的问题。
   
2. **LLM-as-a-Judge（大模型自我裁判机制）**
   这是本系统确保航空安全的**核心壁垒**。在生成最终答案前，系统内部的“裁判模型”会像真实的适航审查员一样，对草稿进行交叉验证。如果发现草稿没有涵盖所有检索到的约束条件，或者缺乏明确的条款引用，裁判会驳回草稿，要求重新检索和生成，确保输出的绝对严谨。

3. **强制的法规溯源标注**
   系统的每一句回答都必须附带来源文献的明确编号（如 `[来源: CCAR-23部.pdf, 章节: 23.853 舱内设施防火]`）。这使得工程师可以随时点击溯源，将系统作为一个高效的法规索引目录，而不是盲目相信 AI。

## 四、 结语

本系统不仅是一个计算机领域的大模型工程实践，更是深度融合了南京航空航天大学**“航空、航天、民航”**特色的交叉学科产物。它致力于成为低空经济从业者的“随身适航专家”，切实降低合规成本，为我国低空经济的安全腾飞保驾护航。
