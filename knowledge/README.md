# 内置低空适航与规章知识库

本目录随代码发布，启动时无需再次上传或调用 Embedding API。

- `documents/`：原项目中的 19 个资料文件。
- `seed.zip`：17 个来源、4,235 个文本块及 BAAI/bge-m3 的 1,024 维向量。
- `manifest.json`：已入库来源清单、文本块数量、模型及数据包版本。
- `not_indexed/`：原项目单独保存、尚未入库的 EH216-S 专用条件。

19 个文件不等于 19 个入库来源：暂行条例的 PDF 与 TXT 是两个文件，原库仅索引 TXT；FAA UAM ConOps 2.0 文件保留在资料目录中，但未出现在原库的 17 个来源中。本次保留原库的入库边界，没有将未处理文件伪称为已索引。

数据包仅包含规章资料文本、来源名称、章节和分块信息，以及重新生成的向量；不包含本地密钥、用户对话、操作日志、个人数据库或电脑路径。原始 SQLite/HNSW 运行目录不随代码发布。

首次启动将数据包恢复到运行目录 `data/chroma_db/`，无需 Embedding 请求。导入按 ID 去重，失败后可重试；成功后记录版本，同一运行目录下不会在每次刷新时恢复用户删除的内容。云端运行目录重建后，随代码保存的数据包会再次恢复。

提问和新增文档仍需要有效的 LLM/Embedding API 配置。内置资料是原项目收集的版本快照，不代表完整法规体系或最新有效版本；适用范围、修订状态和正式原文需要使用者核对。项目代码的 MIT 许可不改变第三方资料原有的权利与使用条件。
